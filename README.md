# Strand

A habit tracker played as a growing DNA strand. Open it at https://chadorleman.github.io/Strand/

- The app is `index.html`, built from `src/` by `python3 build.py`.
- Rules are checked by `node test/engine.test.js`.
- Your data is not stored here. Strand saves it to a private repo of your own (Data → Sync to GitHub in the app).
- How it all fits together: see `CLAUDE.md`.
